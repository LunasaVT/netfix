netfix is a lightweight compatibility mod that resolves networking issues caused by the outdated version of Netty in older Minecraft versions.

---

### What It Does

netfix injects into patchy to remove it's DNS handling and server address checking in order to unblock domain resoultion & remove server IP checks. It also injects into Netty in order to fix lookup problems caused in newer JVMs. 

---

### What It Fixes

If you're experiencing unexplained connection issues, crashes related to networking, or server pinging not working properly, netfix may resolve them instantly.
